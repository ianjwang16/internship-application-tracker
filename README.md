# Internship Application Tracker

A full-stack web application for tracking internship applications,
statuses, dates, job links, notes, and application progress.

## Live Demo

https://internship-application-tracker-sobm.onrender.com

## Features

- Add, edit, and delete internship applications
- Search by company
- Filter by status
- Sort by company, status, or date
- Update application status directly from dashboard
- Track interview and offer rates
- Store application data with MongoDB
- Responsive web interface

## Tech Stack

- JavaScript
- Node.js
- Express
- MongoDB
- Mongoose
- HTML
- CSS
- REST APIs
